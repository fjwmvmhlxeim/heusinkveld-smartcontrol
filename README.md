## Overview

Heusinkveld SmartControl Manager extends the Heusinkveld SmartControl software with profile backup and restore, community profile import and export, pedal response curve visualization comparison, and per-simulator profile launching — making it easy to maintain optimal pedal force settings across multiple racing simulators.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Heusinkveld SmartControl Manager** delivers the features you need in a clean, intuitive package.

> Official website: [heusinkveld.com](https://heusinkveld.com)

## Key Features

| Feature | Description |
|---------|-------------|
| **Profile Backup** | Backup all SmartControl pedal profiles with one-click export |
| **Community Import** | Import community-shared pedal setups from a common format |
| **Curve Comparison** | Side-by-side visualization of multiple pedal response curves |
| **Sim Switching** | Launch simulator-specific profiles automatically with game startup |
